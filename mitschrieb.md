# Feedback Bilder

Brauchen Quellen. In dokument ergänzen
Abbildungsverzeichnis ergänzen
Bildreferenz -> Name bild in ordner
Bildquelle -> Für Abbildungsverzeichnis
Bildbeschreibung -> Zuschreib für Bild in Katalog

Bildreferenz: "bild1.jpg;bild2.jpg"
Bildbeschreibung: "Das Bild hat ein...;Im nächsten Bild..."
Bildquelle: "Herkunft Bild 1;Herkunft Bild 2"

Folgend sollen Bilder Strukturiert sein

<Bild 1>
Abb. 1: <Bildbeschreibung>
<Bild 2>
Abb. 2: <Bildbeschreibung>

Bildbeschreibung ZWINGEND auf gleiche Seite wie das Bild.
